# 🍓 Ana Restaurant — Little Chef

A playful, ad-free cooking game for toddlers, built with React, Vite and TypeScript.

## Run locally

Install Node.js 20+ and run:

```bash
npm install
npm run dev
```

Open the URL Vite prints (normally http://localhost:5173/fungame/).

## Play

A bunny, bear, kitty or panda orders food. Click or drag glowing ingredients into the pan. For omelettes and burgers, turn on the pretend stove and watch a five-second automatic cooking timer. Burgers then need a bun and cheese. Ice cream skips cooking. Plate the food, serve the customer, earn coins and welcome the next guest.

Recipes: mushroom omelette (egg + mushroom, 5 coins); cheeseburger (patty, bun, cheese, 8 coins); strawberry ice cream (cone + strawberry scoop, 4 coins).

No losing, burning, ads or pressure. Coins are stored locally in the browser. Sound can be muted.

## Build

```bash
npm run build
```

Vite's base path is set to `/fungame/` for GitHub Pages project hosting. Deployment is not automatically enabled.
